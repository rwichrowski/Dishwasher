# Kto ma dyżur na zmywarkę?

Prosta aplikacja Android do śledzenia tygodniowych dyżurów przy zmywarce.

## Funkcje

- Automatyczna rotacja co poniedziałek
- Widok bieżącego dyżurnego
- Kalendarz dyżurów (2 tygodnie wstecz, bieżący, 2 do przodu)

## Dyżury

Antek i Weronika zmieniają się co tydzień w poniedziałek.

## Wymagania

- Android 8.0+
- Android Studio (do budowania)

## Budowanie

```bash
./gradlew assembleDebug
```

APK znajdziesz w `app/build/outputs/apk/debug/app-debug.apk`.
